# Medisure Claims Hub

A responsive web prototype for a health insurance claims system, built for my HND Human Computer Interface unit.

**Live demo:** https://shahzad-03.github.io/medisure-claims-hub/

## Features
- Dashboard, patient records, provider records, visit entry, prescription review, claims processing, reports and help pages
- Medication-conflict warnings in the prescription review and prescribing workflow
- Approve, hold or reject claim decisions with status feedback
- Responsive layout for desktop, tablet and mobile, with ARIA accessibility labels

## Design process
- User and task analysis for three user groups: claims administrators, doctors and pharmacy reviewers
- Personas, interface design specification and viewport layout diagrams
- Moderated usability testing (task-based, think-aloud), where all 6 core tasks were completed

## Tech
HTML, CSS, JavaScript (no frameworks). All patient data is fictional.

## Run locally
Download the repo and open `index.html` in a browser.
